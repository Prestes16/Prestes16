## 🌙 Luna Agent

> *Local-first autonomous AI that reads code, audits smart contracts, and hunts bug bounties — 100% on your machine*

[![Stars](https://img.shields.io/github/stars/Prestes16/luna-agent?style=flat-square&color=00d4ff&label=⭐%20Stars)](https://github.com/Prestes16/luna-agent)
[![License](https://img.shields.io/github/license/Prestes16/luna-agent?style=flat-square&color=7c6af7)](https://github.com/Prestes16/luna-agent/blob/main/LICENSE)
[![Website](https://img.shields.io/badge/🌐_lunaagent.dev-live-00d4ff?style=flat-square)](https://lunaagent.dev)

Luna is an Electron desktop app backed by a FastAPI agent loop. It routes tasks across Claude, Grok, and Groq, executes up to 40 chained tool calls per session, and pays for itself via Solana — built for bug bounty researchers who need a private, powerful AI that never sends code to the cloud.

**→ [github.com/Prestes16/luna-agent](https://github.com/Prestes16/luna-agent) · [lunaagent.dev](https://lunaagent.dev)**
